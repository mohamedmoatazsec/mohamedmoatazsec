## What I work on

- **Bug bounty research** on HackerOne and YesWeHack: authorised testing of in-scope production
  web applications and APIs for programs across fintech, SaaS, hosting and consumer brands.
- **Focus areas:** authentication and authorisation flaws (IDOR, broken access control),
  injection, XSS/CSRF, business-logic abuse and API security (OWASP Top 10, OWASP API Security Top 10).
- **Tooling:** I write Python to make the boring parts of an assessment repeatable.

## How I report

1. **Find it** — scope first, then manual testing driven by how the application actually works.
2. **Prove it** — a reproducible chain, every request and response, impact stated plainly.
3. **Help fix it** — remediation written for the people who own the code, not for the triager.
